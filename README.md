# LEFT License  
## License for Ethical & Fair Things

**Copyleft for code, culture, tools and commons.**  
A political share-alike license for people building a fairer world.

---

## What is LEFT?

The **LEFT License** is a copyleft license designed for software, creative works, public-interest tools, activist resources, designs, media and shared knowledge.

It protects common works from:

- privatization
- enclosure
- discriminatory misuse
- reactionary capture
- extractive exploitation

It promotes:

- sharing
- modification
- collective improvement
- source transparency
- democratic ownership
- ecological responsibility
- social justice

LEFT is inspired by strong reciprocal licenses such as GNU AGPL, while extending those principles to broader forms of creation.

---

## Why LEFT Exists

Many free licenses protect freedom to use.

Few ask:

- freedom **for whom**?
- freedom **toward what end**?
- freedom **against which forms of domination**?

LEFT starts from a simple idea:

> Shared work should remain shared, modifiable, and aligned with emancipatory social purposes.

## Core Principles

### 1. Copyleft

If you improve a LEFT work and redistribute it, you must keep it under LEFT.

### 2. Source Availability

If you share the final version, you must also share the preferred editable version.

Examples:

- app → source code  
- poster PNG → SVG/Krita source  
- PDF booklet → editable text files

### 3. Network Reciprocity

If you run a modified LEFT work as an online service, users must be able to access the corresponding source.

### 4. Ethical Alignment

Use of LEFT works is reserved for people and organizations materially aligned with emancipatory goals such as:

- anti-racism
- labor rights
- cooperative ownership
- feminism
- LGBTQ+ equality
- ecological transition
- public goods
- democratic freedoms
- solidarity across borders

### 5. No Reactionary Capture

LEFT rejects uses that materially support:

- racism
- fascism
- xenophobia
- anti-immigrant politics
- union busting
- authoritarian repression
- ecological devastation for profit

## How to Use LEFT

### For any creation, add this notice :

```text
This project is licensed under the LEFT License v1.0
License for Ethical & Fair Things
```

### In a code file, you can also add this in comment at the top of the file :
```js
// SPDX-License-Identifier: LEFT-1.0
```
or
```py
# SPDX-License-Identifier: LEFT-1.0-or-later
```
or
```html
<!-- SPDX-License-Identifier: LEFT-1.0-only -->
```

Those are example to adapt as you see fit.
Include the full license text in your repository.

## Q&A

### Is LEFT open source?

Not under OSI definitions. LEFT is a political copyleft license with ethical conditions.

### Is LEFT anti-commercial?

Not entirely. It favors democratic and social forms of economic activity over extractive ownership models.

### Can I use LEFT for art?

Yes.

### Can I use LEFT for websites?

Yes.

### Can I use LEFT for SaaS?

Yes, but modified network services must provide source access.
