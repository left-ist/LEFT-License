# Governance

The LEFT License project is currently maintained by its founding maintainers.

Our goal is to build an open, democratic and international stewardship process for the license.

## Current governance

For now, maintainers may:

- review Pull Requests
- merge documentation changes
- publish draft versions
- manage repository structure
- moderate Discussions

## License versions

A new official version of the LEFT License should require:

- public discussion
- a clear changelog
- review by maintainers
- publication in the `/versions` directory
- a GitHub release tag

## Translations

Translations may be maintained by contributors, but the English version remains the reference text unless otherwise stated.

## Future governance

The project aims to establish a broader steward group, potentially including:

- legal contributors
- translators
- cooperative actors
- unions
- associations
- public-interest technologists
- political and cultural commons organizers
